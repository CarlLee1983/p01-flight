素材均由正式內建image_gen生成，再離線匯入WebP；12檔共1,561,578B。來源PNG留在忽略的next-generated，提示/來源blob/原始與成品hash/尺寸/座標規格化見 [來源](next-fronts-art-sources.json)。沒有用SVG/平塗多邊形假裝新的完整機體。微型投射物仍用既有Graphics層繪製，飛彈有短尾焰，不顯示敵人未來彈道。

`enemy-roles.ts` 是地面分類與顯示契約；模型、碰撞、統計與測試駕駛共用分類，避免車輛被當成撞機威脅。沒有建立ECS或通用引擎。所有舊角色仍遵守原規則，第一關波次資料沒有改動。

## 關卡與進度

第二關原有編隊/補給/休息/Boss時點保留，加入少量固定教學遭遇：38/40/102/104秒斜切機、66/128秒轟炸機、45秒飛彈車、100秒防空砲。仍有原來7個地炮，不把替換顏色當敵方種類。

第三關補給目標使用完整履帶底盤作無砲架裝甲補給車，放在道路側，避免倉庫在冰水邊緣像浮空；位置/HP/掉落仍由同一角色模型處理。

第三關155秒Boss、205秒上限；雪原破冰水道、鐵道、機場、雷達基地與開闊冰灣為五張新原創材質，不是峽谷圖換色。50–58、108–117、145–155秒不生成新戰鬥機；保留固定補給和休整，原已入場敵人不會憑空消失。seed控制編隊/左右/時間，不在每幀亂生敵人；同seed可重現、重試保留、新出擊換seed。

`stage-catalog.ts` 集中名稱/簡介與配置，`stage-selection.ts` 逐關解鎖，避免第三關被第二關文案/設定硬編碼覆蓋。v1 SAVE_KEY和schema不變，各關成績獨立，第一關舊存檔可解鎖第二關，第二關通關後解鎖第三關。第三關結束沒有不存在的下一關按鈕。

音樂共用既有合法錄製曲目與FlightAudio context API；沒有修改audio實作/署名、增加付費依賴或宣稱有新專屬BGM。

## 渲染與手機

維持global batchSize4096與Image/Text QuadSingle。兩種後續地形共用同一個快取滾動元件，每主題最多九個Image，接縫/邊界只烘焙一次；極地主題等到選取第三關才建立烘焙與顯示物件。原始紋理仍預載，本輪不宣稱已完成按關卡卸載/串流；真手機記憶體和載入時間仍要實測。

素材新增的診斷來源讀取有未就緒保護，不能重犯missing texture尚未建立就中斷RAF觀察者的問題。WebGL calls/RAF只代表共享CI觀測，不是GPU執行時間或真手機保證。
