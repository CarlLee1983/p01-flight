# 機體材質修訂

獨立覆核指出鉤翼機、煞停機、巡邏艦與 Boss 側砲座仍像平塗幾何圖標，不能以「完整輪廓」就宣稱風格統一。這次以原有 Boss 的酒紅裝甲、鋼鐵凹槽、黃銅倒角與橙色散熱孔為材質基準，生成完整原創機體；護航機與尚未出場的空中砲艇也一併匯入同系列。後者只有資產檢查，不能冒稱第二關出場已驗。

- 7 個透明 WebP，合計約134KB；4倍顯示解析度，載入後直接使用 Image，沒有每幀重建貼圖。
- 舊的 canvas 生成器保留作資產載入失敗時的既有降級，不是本輪交付美術；E2E 明確要求所有7個key來自實際 HTMLImageElement，不能只檢查 key 存在。
- 碰撞、血量、波次、子彈、BGM、地圖、batchSize4096 和 QuadSingle 規則完全未改。
- 雙砲機與巡邏艦只在匯入時作分欄座標校準；炮口分別對齊 ±9/y+20 與 ±39/y+32。Boss 砲口維持 y+22，破損版用同一畫布與裝甲位置，截斷砲管、熄滅燈光，避免擊破後突然換成別個輪廓。
- `scripts/art/import-metal-sprites.py` 是離線素材匯入，不是遊戲引擎或執行期依賴。Pillow 只用於尺寸/alpha/座標規格化。原始生成圖保留在獨立工作區，Git只收優化WebP；完整提示與雜湊見來源JSON。
- 源圖與匯入接觸表已目視：細節與材質已不同於平塗版本，但實際同場戰鬥、受擊/爆炸和Boss連接仍需最終CI畫面逐一覆核，不能把靜態素材接觸表當作遊戲驗收。

本機461項（含新增資產契約）、typecheck、build通過；破損Boss實戰截圖與完整E2E，必須以新head CI結果為準。環境本機Chromium仍受socket EPERM限制，實際瀏覽器依最終CI，未聲稱真人手機或音樂聽感驗證。不得自行合併或部署。
