# 敵機攻擊型態與重疊修正

本輪依使用者實玩回饋「敵機攻擊太單調，發出的子彈重疊太多」，比較基準為已交付的 `5d356611fa2413097593c6ec336f747d89d49930`，不把舊單發版當比較基準。

## 根因與改法

前版所有敵人共用0.12秒連射，尾發隨移動後的機體出發。高速機225px/s、敵彈155px/s，兩發相對縱距 `(155−225)×0.12 = −8.4px`，小於敵彈10px直徑；尾發甚至在前發前面，不只是在槍口瞬間重合。straight／weave／cross本來都射垂直雙發，只有飛行軌跡不同。

現在不同職責使用不同攻擊：

- 直線機：兩個相隔18px的槍口同步V形射擊，角度±0.18rad。
- 蛇行機：偏左／偏右雙斜線逐輪交替，不再一律往正下方射。
- 穿越機：依入場方向打斜列；兩條射線分開，不從追上自己子彈的機體位置續射。
- 地炮／炮艇：鎖定方向的雙點射，間隔0.34秒。仍可看到預警後側移，尾發不重新追蹤玩家。
- 重裝：三條扇形射線、兩輪錯拍，間隔0.34秒。
- 護航：三線扇射、兩輪間隔0.4秒，整組只發這一組攻擊。
- Boss：保留三階段及每線四發，間隔由0.12拉至0.22秒，四發分布0.66秒而非0.36秒；名義沿線間距16.8→30.8px。仍使用既有0.65秒預告與每輪間隔，不加未預告角度。

快機預告使用同一份鎖定角度與相同槍口偏移；只畫120px短預告，避免大量一般機把全畫面鋪滿金色線。慢機、重裝、Boss保留既有長預告。沒有降低敵彈傷害、增加玩家血量或更動關卡敵數／時長／存檔。死亡、離場、池重用、炸彈、Boss換階段／破炮仍取消未發射尾彈。

## 可重現比較

執行 `npm test -- tests/overlap-audit.test.ts tests/enemy-patterns.test.ts tests/burst-density.test.ts`。

固定中央、無敵、玩家不射擊，模擬0–125秒；每幀枚舉活躍敵彈，任兩彈中心距離小於12px算一對，累積 `重疊彈對數 / FPS`。這是彈對秒，可超過125秒，不是玩家受傷秒數。分母另記全部活躍敵彈的彈秒。未排除槍口初始片刻，前後使用同一口徑。

| FPS | 前版彈對秒 | 本版彈對秒 | 前／後發射數 | 本版敵彈峰值 |
| --- | ---------- | ---------- | ------------ | ------------ |
| 30  | 252.20     | 102.57     | 502／502     | 31           |
| 60  | 246.62     | 98.92      | 490／490     | 31           |
| 120 | 261.63     | 104.30     | 502／502     | 31           |

60FPS彈對秒下降約60%，以彈秒正規化的比值18.73%→8.23%（下降約56%），不是靠少射子彈取得結果。整體仍可能有不同敵機的射線交會，不宣稱零重疊。正常射擊時擊破會取消慢機尾發，發射數另在雙倍密度測試檢查。

快機單獨225px/s測試：實際兩彈與預告角度一致，發射後0.5秒最短間距大於17px，避免前版8.4px貼合。Boss各階段完整前八輪並等待最後一輪1秒，仍為16→64、40→160、24→96發（相對單發基準皆4倍）。

## 驗收與限制

本機209 unit、typecheck、build；保留相同物件預算，不擴大上限。完整三武器、30／60／120模型、低渲染FPS追幀、存檔與暫停等回歸。前版只按固定時間掃動的部分模型路線無法應對新斜射，測試駕駛改為讀取可見敵彈方向、以正常左右控制閃避，再回中央集中火力，危險時放開慢速瞄準。沒有更改模型生命／時間、沒有免傷通關；所有正常路線仍必須通關。21項瀏覽器E2E不修改，仍驗證真實輸入。

本機系統Chromium既有socket EPERM不繞過。最終CI、影片目視、私人站部署需核對本輪精確head，不能沿用5d356611的綠勾。人工趣味、難度、真機效能與聽感仍待實玩，不用彈量或重疊數代替玩家判斷。依賴漏洞仍為獨立待查事項，本輪未升級依賴或變更鎖檔。
