# 沿岸突擊：第一關玩法與街機呈現

本輪回應實際試玩：「敵機、武器及整體介面缺少遊戲感」。不追加第二關。

- 75 秒內擊破指揮艦。2–10 秒小編隊、15–28 秒交錯突擊、32–40 秒重裝防線、46 秒補給、55 秒頭目。
- 主炮由單射升至三向/五向，金色能量永久升級（本次航程）；X 主動炸彈兩枚，清彈、傷敵與短無敵。按住不連續消耗。
- 頭目 HP 門檻三階段：雙向瞄準、扇形、加速橫移瞄準，切階段預告並清舊彈。敵機射前有光圈預告。
- 原創沿岸地形/港設施與街機機台控制台；標題雷達、三行HUD、敵機外形/顏色/大小、勝敗大字及炸彈光環。四張既有 Kenney CC0 圖未換來源。
- 原創 Web Audio 振盪器合成射擊/爆炸/升級/炸彈/勝敗音與簡單節奏；沒有下載或挪用商業遊戲音樂。音樂和音效音量沿既有欄位，0 靜音，全部靜音按鈕會保存。需要使用者開始操作才解鎖 AudioContext，背景分頁/暫停停止聲音。
- 仍為純靜態、無新增 runtime API 或後端，localStorage key/schema v1 不變；舊成績保留但不作跨版本公平排名。

## 驗證

本機35個單元測試、typecheck、build通過；模型30/60/120FPS正常中心連射可在約67–69秒通關，這不是壓測或真人手感結論。另測62/65秒炸彈操作、三階段、重開、暫停、聲音voice上限/靜音/不支援環境等。
本機Chromium在開頁前因socket EPERM退出，不能把它當遊戲失敗或宣稱已本機試玩。精確遠端CI與最終截圖結果見PR及Notion；音效API運作不等於人工聽感完成。正式私人站部署由協調者更新，登入後既有玩家存檔仍需另驗。
