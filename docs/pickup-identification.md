# 戰鬥中的補給辨識

基準76537fe9。保留使用者認可的機械模組造型、碰撞和效果，不回到發光徽章。

- 在各模組實體外殼加類別識別漆帶，顏色只作輔助；修理箱、能源包、多管炮、雙軌、飛彈掛架、雙僚機輪廓仍不同。
- 掉落物下方有不旋轉的兩字標籤：修復／升級／散射／光束／飛彈／僚機。黑底白字、左窄類色條，72×28一次生成，36×14顯示，沒有每幀建立文字或texture。
- 標籤在敵彈／預警效果下層，飛行彈體能蓋過標籤；標籤與實體同在HUD下層，只在掉落物進入HUD下方後顯示；標籤隨物件自然出場，由畫布裁切，不釘在底部留下孤立文字。沒有新增箭頭、彈道線或大型光圈，保持和敵彈差異。
- 拾取後顯示實際結果：裝甲2/3、火力LV2/3、貫穿光束LVx、追蹤飛彈LVx、僚機支援8秒等。使用拾取後狀態，不無根據宣稱已補滿或升級成功；原短安裝動畫及聲音保留。

驗證項目：六類標籤和alias、texture尺寸與一次快取、類色識別帶、結果訊息單測；正常完整關卡在真實拾取後讀取實際顯示的notice字串。CI新增320寬六類指南、單色指南與戰鬥中落下模組畫面。單色畫面只驗證不依賴顏色，並非所有色覺缺陷模擬或臨床可用性研究。所有生命、關卡、敵機、武器效果與存檔規則不改。

本機Chromium受socket EPERM限制，透過精確CI瀏覽器操作與產物目視，不繞過。實體手機、真人辨識速度、手感與人工聽感仍需實玩回饋。
