# 第四、五關

雲頂發射場依序經過跑道、攔截艦與雲層；52 秒的小頭目先教單一道光束，148 秒出現的天門陣列再加入慢速橫掃。星門決戰從近地軌道進入殘骸航道，164 秒迎戰星門核心。星門有不同形體、雙列光束與三個可破壞的飛彈節點，擊破核心即完成本篇戰役；沒有第六關或彩蛋關。

- 兩關採資料化編隊與獨立原創 SVG 地圖及頭目素材。原有敵機、砲塔、音樂與存檔沿用。
- 光束只在實際發射時造成傷害；充能用發射口與畫面底部標示，不畫一般敵彈的預測軌跡。渲染和碰撞共用中心線及寬度；光暈不算傷害。光束終止後，頭目有回擊空檔並射出獨立彈幕。
- 第四關通關才解鎖第五關；原有 v1 前三關紀錄及音量設定不變。模型驗收與 Playwright 實頁驗收分開，後者以此 PR 最新 head 實際結果為準。
