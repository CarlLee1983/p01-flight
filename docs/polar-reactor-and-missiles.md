# 第三關極地雷眼與敵方飛彈

- 敵方飛彈共用原創 SVG 外形：明亮彈身、收尖彈頭、橘色識別帶、深色輪廓與實際速度方向上的短尾焰。保留原判定、航速、11 × 26 顯示尺寸和一枚對應一個池化 Image 的設計；不畫未來彈道。
- 極地雷眼不再沿用一般砲艇機身。中央爐體和四支獨立連桿為原創 SVG，連桿沿現有部件掛點展開，擊毀後縮成殘臂。核心亮度跟隨可攻擊狀態；既有核心、護甲、碰撞與血量契約保留。
- 第三關 Boss 最後階段交替使用鎖定飛彈及雙側飛彈。前者先鎖定再打出分叉電漿；後者先放電漿，再由核心兩側開火，等中線電漿過去可穿回。提示留在 Boss 附近和 HUD，不畫軌跡。同一波維持五枚核心投射物，末段的波次冷卻設定由 0.96 秒縮為 0.84 秒（換位與尾彈視窗仍可能拉長實際間隔），第一、二關 Boss 的玩法未改。
- 第四關起沿用炮口、可破壞部件、充能提示與測試契約，不複製這套外形與節奏。第四、五關不在本次程式範圍。
