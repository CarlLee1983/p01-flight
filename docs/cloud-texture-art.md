# 沿岸薄雲紋理

原背景是三組低透明橢圓，只有遮罩形狀。新 `cloud-art.ts` 用固定種子的多尺度值噪聲、輕量座標扭曲與邊緣羽化，建立不規則棉絮、薄厚層次和局部透光窗口。沒有外部素材或隨機時鐘，也不是單純疊三個圓。

## 整合介面

- `CLOUD_ART.bank`：`cloud-bank`，256×160來源、建議224×140顯示，alpha 0.26。
- `CLOUD_ART.wisp`：`cloud-wisp`，192×224來源、建議144×168顯示，alpha 0.22。
- `createCloudTextures(scene)`：Scene啟動時建立兩張CanvasTexture，存在即略過。
- `generateCloudPixels(kind)`：純RGBA資料，用於可重現測試及離線預覽。

使用普通alpha混合，不用ADD發光。放在地景之上、敵機／地面目標／敵彈之下；不把數張重疊在中央射擊區。每幀只移動已建Image，不重新生成紋理。兩張總計83,968像素，RGBA約328KiB，不計GPU及引擎額外記憶體。

## 已驗證與限制

逐像素測試確認固定輸出、全透明外框、100種以上透明階、內部透光窗口、RGB不到230、原生alpha不超168。建議alpha乘上後峰值約0.17／0.15，刻意低於彈幕對比。測試也確認快取一次和分配失敗不崩潰。

本機初次生成兩款分別約23ms／11ms，僅一次採樣，不能當手機效能承諾。已用同一純函式RGBA資料輸出PNG並目視，首版過度扭曲煙霧已修成較細碎棉絮薄雲；不是實際Phaser視差或遊玩驗收。最終仍需實頁確認地景、HUD、敵機與彈幕可讀性及捲動連續性，建議透明度可依實頁調整。
