# 第一關的遭遇節奏

此輪回應實際試玩「過程單調」，不是再新增一關或拉長時間。維持115秒上限與70秒指揮艦。既有鍵盤、相對拖曳、雙指操作和v1存檔保留。

## 一條有轉折的航線

外海短編隊先辨識射界；進入防波堤後要處理側向攔截，追蹤彈比較容易追擊。32秒地面砲台配合預告瞄準，玩家要區分地面目標與飛越無碰撞的裝飾。40秒加入巡邏艦中段高潮，取代五架重複砲台／重裝機，不額外疊加。巡邏艦橫移、先封左再封右最後鎖定瞄準，預告0.75秒且不追蹤已鎖定的位置。50秒最後俯衝推進，60–70秒真正清空殘餘敵機與敵彈，讓玩家補給再進指揮艦。

巡邏艦有98px寬艦體輪廓和獨立血條，生命64，正常散射約7–8秒擊破，沒有為拉長演出加無敵。貫穿炮集中對準、追蹤彈追擊橫移、散射兼顧附近目標；並非強制切換才可過。擊破有1000分與升級包，若放過則9秒後停止攻擊撤離，不把漏殺變成隱性失敗。

場景由開闊海岸、雙側港門、工業港池交戰場、開闊補給水域到指揮艦邊緣；地景負depth只呈現環境，不能把裝飾畫成有碰撞的牆。所有地面目標仍採32px/s世界速度，持續視差沒有停止。

## 可複用內容

Wave.behavior=gatekeeper，使用hp、speed、fireEvery、holdFor、strafeWidth、drop組合。這是小型敵人行為，不是通用引擎。攻擊診斷提供attackPattern、attackLanes世界座標、telegraph和aimAngle；render只顯示規則，不反過來決定傷害。

背景區段和地標仍配置可重排；HUD航程分段數量由sections計算，不硬編五段。聲音強度隨精英／頭目提高，補給期下降，音量設定維持本機紀錄。

## 驗證邊界

單元驗證巡邏艦預告、攻擊順序、撤離與重開、30/60/120FPS正常通關和原有規則。瀏覽器新增真實鍵盤到中段的預告／反擊錄影，不改遊戲時間或取消傷害；既有完整觸控及鍵盤通關、失敗、存檔、尺寸與WebKit保留。最終結果以精確CI為準。主觀趣味、真機手感及人工聽感不能由通過測試推定。
