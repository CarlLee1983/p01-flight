# 行動裝置支援

本輪保留 Stage 01、原武器敵人和本機存檔，沒有製作第二關。觸控是鍵盤之外的輸入方式，不改遊戲速度或讓手指直接瞬移戰機。

## 操作

手指在遊戲畫面按下後，以相對拖曳移動並持續射擊；抬起即停止射擊。不必遮住戰機，初次按下不會將戰機拉到指尖。模型追隨拖曳目標，速度上限仍240邏輯px/s，小距離不越過目標。第二根手指可以使用側欄炸彈、換武器及暫停，不會接管第一指。原桌面鍵盤完整保留。

pointercancel、失去capture、視窗失焦、切分頁、暫停、重試、尺寸改變清掉觸控狀態，避免黏住射擊或旋轉後使用過期座標。音訊仍須用使用者手勢解鎖，靜音及音量沿v1儲存。所有分數與通關紀錄只存在目前瀏覽器與同一origin，不跨裝置同步。

## 版面

舞台維持9:16，以可用寬度與高度共同限制，不只依手機寬度放大。viewport-fit=cover與safe-area預留；側欄52px按鈕、菜單控制至少44px。短橫向隱藏頁首，菜單可以內部捲動。只有遊戲canvas使用touch-action:none，不取消整頁縮放。直向是較適合的體驗；未提供觸覺回饋或PWA離線包裝。

## 驗證與限制

新增純TS觸控模型測試，包括CSS縮放、單指ownership、取消、邊界、30/60/120FPS速度及小距離不overshoot，保留原有碰撞及鍵盤通關測試。瀏覽器測試涵蓋320×568、390×667、412×915、844×390尺寸，Chromium真實touch事件與雙指炸彈、取消/旋轉、完整觸控通關、localStorage重新載入；Linux WebKit驗證啟動/觸控按鈕/音訊解鎖。最後結果以精確CI為準。

模擬行動瀏覽器不等於iPhone/Android真機，不能宣稱真機手感、長時間觸控疲勞、瀏覽器工具列變動或實機音訊已驗證。共享CI錄影效能不代表一般手機穩定60FPS。本機瀏覽器socket EPERM限制仍存在，不繞過限制。
