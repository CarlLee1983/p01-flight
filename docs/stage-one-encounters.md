# 第一關場景與遭遇組合

本輪只充實 Stage 01，仍以 115 秒為上限、70 秒進入頭目戰，不建立第二關。目的是交替安排試探、側向攔截、地面設施、整備與頭目互動，而非單純延長時間或增加同屏敵人。

## 關卡節奏

- 0–15 秒：外海試探與簡單編隊，學會射擊及升級。
- 15–32 秒：交叉航道與側翼攔截，沿用慢速補給機的武器選擇。
- 32–56 秒：港區，地面砲台／補給站取代部分空中重裝單位，與空中角色形成不同目標優先度。
- 56–70 秒：整備接近，停止新攻擊波次，保留恢復與僚機補給；殘存敵機不瞬間消失。
- 70 秒後：指揮艦。核心可直接攻擊，兩個側炮可獨立擊破，停止對應側的外緣彈；破壞不是通關硬性條件。沒有增加既有彈幕總密度。

## 可重用的配置

`src/data/stage.ts` 的 `StageConfig` 描述畫面、時限、段落、波次、補給、頭目。`Wave` 重用既有移動／攻擊職責，以 at/x/spawnY/hp/fireEvery/drop 等值組合；新的波次不需再寫一份敵機類別。武器、補給與碰撞由小型模型共用，不引入 ECS 或通用編輯器。

地面目標使用 `groundBattery` 或 `groundDepot`，共用背景捲動速度。前者有預告瞄準射擊，後者不開火；兩者可擊毀／設定掉落，不會因玩家飛過上方而造成機身碰撞。每個地面目標的座標等於出生位置加上經過時間乘地面速度，不會停在畫面上追隨玩家。進入 HUD 下方可玩區後才接受射擊，避免出現即被不可見地摧毀。原創底座、炮座與貨艙以 code-native Canvas 繪製，無第三方圖像。

`CoastalBackground(scene, areas?)` 接受 `CoastalAreaConfig[]`，每段指定 id/label/at/fade/scenery。既有外海、航道、港口、接近與指揮艦地景可重排／重複，單元測試用另一組時序證明，不新增實際第二關。背景、地面目標必須使用一致捲動速度；中央航道保留低對比，目標放在岸緣自帶棧台底座。

## 作者流程

1. 複用 StageConfig 與既有敵人行為，先列時間段和每段需要的玩家決策。
2. 組合 waves/pickups，設地面目標掉落及攻擊間隔；避免無目的地堆敵。
3. 配置相符背景段落，不重製引擎與素材。
4. 跑 typecheck/unit/build，再用真實鍵盤跑通關、失敗、重開與存檔測試；以影片與截圖檢查轉場、彈幕和地面速度。
