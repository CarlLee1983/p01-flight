# HUD 分層、側炮與預告精簡

基準：已部署 ff1ff46e。這輪不改模型、彈道、彈量、傷害、預告時間或儲存。

- 根因：HUD底板原在戰鬥overlay depth3，道具/部分敵機depth4，因此穿入頂欄。新增獨立不透明HUD圖層4.5，文字5；所有戰鬥內容仍≤4。每幀清空重畫，選單不留底板。實頁診斷讀實際可見sprite最高層，不僅回傳預設常數。
- 查核既有素材：原創Boss機體可沿用；ground-turret是圓形地炮，不適合硬貼到機翼。沿既有pickup CanvasTexture流程建立原創削角裝甲側炮，暗鋼/紅帶/舊銅配色、陰影側板與中央實體炮管。非新外部素材，來源為程式原創幾何。破壞保留殘架而非矩形X；32×48顯示，炮口y+22與既有bossMuzzle一致，不改hitbox。
- 相同中央反應爐的3條預告射線原各畫一次充能環，現在只畫一組小光芯及兩側短標記；每條虛線、角度、時長皆保留，破壞炮管不畫預告。換階段大圓改機體兩側括號，避免罩住整艘。

新增模型/幾何測試與實頁HUD深度驗證。完整實頁、窄版、動畫與性能尚待精確CI，不以單測稱美術已驗收。先前私人站ff1ff46e保持不變，本輪不自行部署或合併。
