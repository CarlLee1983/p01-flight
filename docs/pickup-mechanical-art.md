# 可拾取機械補給模組

六種道具改為原創 CanvasTexture 物件，而非發光徽章：修理工具艙、三芯能源包、多管散射炮、雙軌光束模組、三枚飛彈掛架、雙僚機停泊組。輪廓、材質分面與明暗可區分，不只換色；用寬色塊和厚炮管保留32px可讀性，沒有小字或外圍霓虹漸層。底部深色偏移表示物件厚度。

保留既有六個 key、kind、label、shortLabel、pickupVisual aliases、64×64 texture 與建立／快取API，未改道具效果、掉落、UI或碰撞。

驗證：typecheck、既有pickup-art三項及新增材質／範圍測試通過。新增測試確認六種素材不越64px畫布、不使用微小文字／霓虹漸層、每張繪製呼叫少於85（只建立一次，並非每幀）。

已從相同繪圖指令生成128px及32px對照圖目視，輪廓與武器種類可分。此圖為指令追蹤的離線預覽，不是Phaser實頁截圖；Canvas抗鋸齒、實際背景對比、掉落動畫、行動裝置可讀性仍需由最終CI／實頁確認。未宣稱本輪已完成完整瀏覽器驗收。
