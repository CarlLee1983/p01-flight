# 第一關一致機械敵方材質

新 `enemy-modules-art.ts` 以原創CanvasTexture完整輪廓取代把scout/heavy圖疊在方框、三角或紫色條上的拼貼。沒有第三方素材、沒有改傷害／碰撞／攻擊。

- 護航機：70×44，寬後掠翼連裝甲進氣艙，細長中央機身與短三孔扇形發射器，中央炮口0,+20。左右艙只畫橫向進氣柵，不暗示雙炮；保留原護航扇形彈受擊路線。
- 重型巡邏艦：104×76，寬裝甲肩部、長側砲艙及受保護艦橋，炮口±39,+32。
- 空中砲艇：56×49，短粗機翼、雙渦輪與中央單砲，炮口0,+17。
- `boss-support`：184×100中空肩架，暗鋼承力件／紅銅護板／暖金鉚釘，接既有主體與側砲。位於主體及砲座之下，未重造完整／受損炮座，未新增碰撞。

共用暗鋼、紅銅、暖金、低彩度玻璃材質與寬分面；不使用霓虹外框。顯示尺寸為邏輯像素，來源texture以2倍尺寸一次建立／重用。

介面：`ENEMY_MODULE_ART`、`enemyModuleVisual(kind)`、`createEnemyModuleTextures(scene)`；後者也建立 `BOSS_SUPPORT_ART`。同一來源繪製函式可用`paintEnemyModule`／`paintBossSupport`離線驗收，不另維護一份預覽設計。

驗證：固定尺寸、炮口黑色開口末端、材質／圖元界限、中心透明肩架、四張快取與分配失敗測試。用相同繪製函式的指令追蹤輸出2倍／實際尺寸contact sheet，已目視三種輪廓與材質一致。離線重播抗鋸齒與Canvas可能不同；不是Phaser實頁／動態命中／手機驗證，仍需整合後核對與預警及彈道的對齊。沒有單靠單元測試宣稱已達成品美術品質。


## 第二輪正常材質檢查

檢查實頁 `patrol-counterattack.png`（巡邏艦正受暖色命中加亮）及 `escort-formation.png`（可見護航機正常材質）後，針對正常材質的扁平感做小範圍補強：三款機體增加寬面裝甲的上緣受光、暗側壁與下緣承接面，機身右側收暗，座艙改深色凹面加一塊低亮反射。沒有細線／雜訊堆疊，也不將受擊加亮誤認為原材質。

保留全部輪廓尺寸、炮口座標、快取 API 與 Boss 肩架；沒有改 gameplay。相同函式離線 contact 前後圖已目視，實際顯示尺寸可見座艙深度與肩部裝甲分面；這只是局部改善，尚未使程式美術完全等同既有半寫實小機風格。新的實頁／受擊動畫還需整合驗證。
