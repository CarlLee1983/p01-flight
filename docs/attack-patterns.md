# Stage 01 攻擊預告與應對

本輪只調整第一關既有敵機與 Boss 攻擊，不增加彈量、敵人總量或第二關。405 架航空敵人包含 6 架供應機；排除供應機後為 399 架戰鬥小怪。玩家血量、移動速度、炸彈與 v1 存檔不變。

## 模型與控制參數

角度統一使用 `sin(angle)` 決定 x 方向、`cos(angle)` 決定 y 方向，0 為向下。虛線僅是預告，不是雷射或碰撞物。

| 角色          | 預告與攻擊                                                                                               | 玩家可以怎麼回應                       |
| ------------- | -------------------------------------------------------------------------------------------------------- | -------------------------------------- |
| 俯衝機        | 出場滿 1 秒鎖定方向；1–1.7 秒停留預告；之後沿原方向以 260 px/s 俯衝，不在預告結束時重新追瞄              | 看見線後側移，把俯衝引向舊位置         |
| 重裝機        | 每輪最後 0.6 秒顯示三線；基礎角度 -0.4、0、0.4 rad，奇偶輪分別偏 -0.14、+0.14 rad；仍每輪 3 發、135 px/s | 觀察輪次偏轉，從扇形空隙移位或優先擊破 |
| Boss 第一階段 | HP 高於 67%；兩條相對鎖定瞄準角 ±0.25 rad 的夾擊線                                                       | 預告後離開舊位置，不必追著 Boss 橫移   |
| Boss 第二階段 | HP 高於 34%、不高於 67%；五線 -0.5、-0.25、0、0.25、0.5 rad，輪次交替偏 ±0.1 rad                         | 缺口會換位置，依虛線選安全走廊         |
| Boss 第三階段 | HP 不高於 34%；鎖定瞄準角及 ±0.3 rad 三線；射擊間隔乘 0.7                                                | 利用預告側移，必要時用炸彈清彈         |

Boss 設定維持 400 HP、125 秒入場、140 px/s 敵彈、基礎間隔 2.7 秒。正常每輪最後 0.65 秒預告，鎖定後不因玩家移動重算角度。入場尚未完成不消耗射擊倒數；第一輪也保證至少 0.65 秒預告。轉階段保留 1.2 秒提示並清除前階段殘彈。

側炮仍可擊破。左／右側炮分別控制第一／最後一條外側射線；破壞後不再預告或發射該線。核心仍能直接受傷，擊破核心即可通關，沒有強制拆炮順序。

## 渲染資料與座標審查

- `Enemy.attackAngles`：重裝蓄力期間的三條角度；`Enemy.telegraph` 為剩餘預告秒數。
- 俯衝機的 `aimAngle` 與 `diveAngle` 在預告開始時相同；移動要等到 1.7 秒才開始。
- `Boss.attackWarning`：每輪剩餘預告時間；`attackAngles`：鎖定角度；`attackCycle`：已完成射擊輪數。
- `Boss.telegraph` 仍表示轉階段提示，不能當成每輪射擊預告。

已以原始碼核對 `main.ts` 與 `model.ts`：重裝虛線基準點 `(enemy.x, enemy.y + 20)` 與子彈出生點一致；Boss 為 `(boss.x, boss.y + 28)`，同樣一致。俯衝線從敵機中心開始，對應機體移動路徑而非子彈。線段為避免遮住機體，分別從基準點前方 20／40 px 開始畫，不代表出生座標改變。

角度鎖定不等於世界座標整條線凍結：Boss 在蓄力時仍橫移，預告原點隨 Boss 移動，子彈從發射當刻原點出發。側炮目前是控制外側射線的可破部件；射線並非從側炮貼圖中心發射。這是現有模型與畫面一致的設計限制，不應描述為獨立炮口模擬。

## 已驗證

新增 `tests/attack-patterns.test.ts` 共 15 項機制測試，涵蓋 30／60／120 FPS：

- 俯衝預告中停留、方向不重瞄，正常移速可以側移。
- 重裝左右交替，預告角度等於實際子彈速度方向，沒有增加發數。
- Boss 各階段鎖定預告、破側炮減少外側彈、暫停凍結倒數、重新開始清除狀態。

既有完整正常操作路線未削弱斷言：30／60／120 模型 FPS，以及透過 `advanceFrame` 的 10／15／20／30／60 渲染 FPS，三武器均通關，實際觀測到 405 架航空敵人進入可視區。60 FPS 代表結果：

| Boss 武器 | 通關時間  | 剩餘 HP |
| --------- | --------- | ------- |
| 散射      | 147.68 秒 | 2       |
| 光束      | 148.18 秒 | 2       |
| 飛彈      | 152.92 秒 | 1       |

路線是持續射擊、70 秒後追擊預告地炮並回中、125 秒切武器、140／146 秒炸彈；飛彈路線另在 150–150.3 秒精準右移。這些是模型輸入測試，不是無敵、直接指定通關或手動改 HP。機制隔離測試中直接設定 Boss HP 只用來覆蓋各階段，不當作正常通關證據。

本輪全套 185 tests 通過，TypeScript typecheck 通過。無射擊的排程負載隔離測試峰值仍為 30 個敵人物件、11 個敵彈；保護測試角色只為量測完整排程，並非正常遊玩測試。
