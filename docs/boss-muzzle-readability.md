# Boss 炮口與預告對齊

使用者要求第一關持續精緻化。本輪延續16914199彈幕修正，解決「側炮可破壞，但所有子彈與預警仍從機體中心發出」的視覺／機制不一致。

外側射線從左右可破壞炮管末端（機體中心x±68、y+42）發出，內側射線保留核心（y+28）。共用bossMuzzle計算預警與首發，連射尾彈沿既有相對位置跟隨Boss，破炮仍取消對應尾彈。炮口充能光圈讓玩家辨認發射來源，而不是只看到一條全畫面虛線。

保留每階段原角度、預警0.65秒、每線四發、0.22秒間隔、Boss血量與玩家能力；沒有為補足側移後出界的子彈額外增加射線。外側射線因此更靠外，這是可見炮口位置造成的幾何改變，不宣稱威脅分布和前版完全相同或難度更好。後續應依使用者實玩決定是否修改攻擊目標，不能只靠發射量宣稱平衡。

新增30/60/120FPS測試，逐輪檢查首發與三輪尾發均從當時可見炮口發射、角度符合鎖定預告，核心位置與破炮狀態一致。保留完整三武器通關、尾發取消、四倍數量及21項瀏覽器回歸。最終精確CI和影像另記PR／Notion；本機Chromium socket EPERM不繞過，真人手感與真機尚未驗證。
