# 第一關攻擊與配樂增量

保留399戰鬥小怪、6補給機與170秒上限，不把敵彈簡單乘倍。俯衝機預告開始鎖線，重裝三線扇射左右交替，Boss每輪0.65秒以上預告。金色虛線是預告不是傷害光束；粉紅實心彈仍是威脅。Boss三階段為夾擊、左右偏移缺口、瞄準散射；側炮被破移除相應外線。玩家可誘導後側移，沒有亮完才追瞄。

原創配樂由旋律、和弦、低音、打擊合成，flight正常段落、pressure巡邏艦變奏、recovery喘息、boss專屬主題。下一小節才切換，避免硬斷音；新局重置，暫停續奏，隱藏停止。音量/靜音與v1存檔保持。WebAudio必須手勢解鎖，沒有自動播放繞過。來源及作曲細節見音樂製作紀錄。

驗收包括精確head的全部unit/build/typecheck和真實鍵盤/觸控通關、Boss預告截圖、配樂上下文/音符實際排程、暫停續奏、離線PCM非零/峰值/段落差異。離線合成與機器斷言不能代表人工聽感、iPhone真機或趣味評估。最終CI/影像結果另補Notion與PR，不提前聲稱上線。
